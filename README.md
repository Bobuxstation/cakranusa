## All About Cakranusa

Cakranusa is a city-building game set in a fictional city in Indonesia. It features plants, buildings and weather inspired by their real counterparts. Currently, the game offers some unique mechanics like corruption, pollution and tourism with more to come.

## Building and Contributing
To run and build the source code of Cakranusa, you need node.js and npm.

Clone this repository and install all dependencies
```
git clone https://github.com/Bobuxstation/cakranusa.git
cd cakranusa
npm install
```

To start the game

```
npm start
```

Build Cakranusa for any supported platform

```
npx electron-builder
```
